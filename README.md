# BEAST AI — Your Personal Video Radio

A public landing page for the BEAST AI early-stage concept.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `beast-ai-support`.
2. Upload `index.html` to the repository root (the top level, not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site.

Your URL will be:

`https://brainforcegit.github.io/beast-ai-support/`

Replace `brainforcegit` with your actual GitHub username.

This is an early-stage concept page. Add your real contact links before sharing it widely.
